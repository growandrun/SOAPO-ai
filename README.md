# SOAPO 재활노트

작업치료사의 SOAP 노트 작성과 환자의 가정 재활을 AI로 연결하는 서비스의 프로토타입입니다.

- **치료사**: AI가 SOAP 초안을 만들고, 흔한 기록 실수(측정값 누락, 모호한 표현, 목표와 연결되지 않은 평가, 복사한 기록)를 실시간으로 점검합니다. 환자별 위험 신호를 자동으로 알려 줍니다.
- **환자**: 휴대폰이나 노트북 카메라로 운동 각도와 횟수를 측정하고, 자신의 회복 기록을 쉬운 말로 확인하며, 치료사와 메시지를 주고받습니다.
- **로그인**: 이메일 매직링크 방식입니다. 환자는 치료사가 준 초대 코드로 가입합니다.

## 바로 보기

`prototype/index.html`을 Chrome이나 Safari로 여세요. 설치할 것은 없습니다.

- 데모 계정: `therapist@demo.kr`(치료사), `patient@demo.kr`(환자)
- 새 환자 가입 체험: 처음 보는 이메일 + 초대 코드 `SOAP-1002`
- 카메라 측정은 휴대폰·노트북에서 파일을 직접 열거나 `npx serve prototype`처럼 로컬 서버로 열 때 작동합니다. 카메라를 못 쓰는 환경에서는 시뮬레이션으로 체험할 수 있습니다.
- 데이터는 그 브라우저에만 저장됩니다. 로그인 화면의 "데모 데이터 초기화"로 처음 상태로 돌아갑니다.
